# 工程目录

默认工程根目录为 `<local SDK or checkout path>`，如果用户提供其他检出目录则以用户目录为准。

## 权威源码

- `SKF\D8Skf.h`、`SKF\D8Skf.cpp`：公开 SKF ABI 和主要实现。
- `D8Dll\D8Dll.vcxproj`、`D8Dll\D8Dll.def`：Windows DLL 与导出表。
- `D8Static\D8Static.vcxproj`：Windows 静态库。
- `linux\D8LibusbTransport.cpp`：Linux libusb 传输层。
- `linux\D8SKF.exports.map`：Linux 导出符号规则。
- `macos\D8MacTransport.cpp`：macOS IOKit 传输层。
- `D8UserManagerV2`：带资源的 MFC 用户管理及测试工具。
- `可给用户自行编译`：交付客户自行编译的 Linux 源码包。

## 标准输出

- Windows x86/x64：`bin\Win32\Release`、`bin\x64\Release`。
- Linux x64：`bin\linux\x86_64-glibc231\libD8_x64.so`。
- Linux ARM、ARM64、LoongArch64、Loongson：`bin\linux` 下对应目录。
- macOS：`bin\macos\x86_64`、`arm64`、`universal`。

## 外部资源

- Linux 工具链和 OpenSSL：`<local SDK or checkout path>` 及相邻 OpenSSL 目录。
- macOS SDK：`<local SDK or checkout path>`。
- 当前发布目录：`\\Desktop-ui6sarr\cd\新开发包\SKF开发包\头文件及库文件`。

这些是环境路径，使用前先确认存在，不能当作仓库内固定依赖。
