# 测试流程

## 安全枚举

1. 调用 `SKF_EnumDev(TRUE, NULL, &size)` 查询长度。
2. 分配 `size` 字节并再次调用。
3. 逐个解析 NUL 结尾的设备名，直到最终空字符串。
4. 分别连接每个设备并检查 ID 版本为 26。
5. 对每个句柄先用空缓冲区调用 `D8SKF_GetDevSerialNumber` 查询长度，再用有界缓冲区读取序列号。

三把相同 VID/PID 的设备应得到三个设备路径，并能分别读取唯一序列号。

## 非破坏性测试顺序

连接 → 必要时做设备认证 → 打开应用 → 验证所需 PIN → 打开已有容器 → 检查密钥和证书 → 执行只读或往返测试。

覆盖 SM3、SM4 ECB/CBC、SM2 签名验签与加解密，以及已经实现的 RSA、HMAC、密钥协商接口和 Init/Update/Final 多包接口。条件允许时与独立软件实现对照。

## 证书流程

- 签名：锁内生成签名密钥 → 用对应公钥生成 CSR → CA 签发 → 检查公钥匹配 → 导入签名证书。
- 加密：锁内生成加密密钥并配置匹配证书，或通过 `SKF_ImportECCKeyPair` 导入批准的加密私钥封装。
- 分别导出签名证书和加密证书，并与各自公钥匹配验证。

发生错误时报告失败 API、完整十六进制 SKF 错误码和最后成功步骤。没有证据时不能把通用错误 `0x0A000001` 固定解释为单一原因。没有硬件时完成加载、符号、依赖和软件向量测试，并明确标注设备测试未运行。
