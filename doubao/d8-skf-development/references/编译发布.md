# 编译与发布

## Windows

用 Visual Studio/MSBuild 编译 Win32 和 x64 的 Release 配置，同时生成 `D8Dll` 和 `D8Static`。确认 DLL/导入库导出 `D8SKF_GetDevSerialNumber` 和要求的 `SKF_*` 接口。按现有配置静态包含 OpenSSL。

## Linux

优先使用 `linux/build_x64_libusb_existing.sh`、`linux/build_all_arch_libusb_existing.sh` 和 `linux/build_all_arch_so.sh`，交叉工具链位于 `<local SDK or checkout path>`。用 `file`、`readelf -Ws`、`readelf --version-info`、`objdump -p` 检查架构、导出符号、GLIBC 上限以及是否仍动态依赖 OpenSSL/libusb。

## macOS

在 WSL 中运行 `macos/build_macos_universal.sh`，SDK 使用 `<local SDK or checkout path>`。生成 x86_64、arm64、Universal 2 三种 dylib，检查 Universal 同时包含两个架构并导出要求的 SKF/D8SKF 符号。

## 发布

将 `SKF\D8Skf.h` 复制为 `SKF.h`，再把每个平台经过验证的库复制到对应目录。保持既有文件名，包括小写 `libD8_loongarch64.so`。复制后比较源文件和目标文件 SHA-256；构建失败时不能用旧文件冒充新产物。
